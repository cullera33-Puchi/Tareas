# Tareas

Gestor de tareas personal para iPhone (PWA). Sin build: `index.html`, `css/`, `js/`, `sw.js`, `manifest.webmanifest`, `icons/` y `vendor/` se publican tal cual con GitHub Pages desde la rama `main`, después de pasar las pruebas.

- Especificación y reglas de trabajo: `CLAUDE.md`
- Entregas por versión: `CHANGELOG.md`
- Pruebas: `npm ci`, `npx playwright install chromium` y `npm test` (detalle en `CLAUDE.md`, sección 7 bis)
